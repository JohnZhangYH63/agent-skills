# 冻结任务包合同

每包只交付**一个**可以独立验证的结果。删除不适用字段前，先确认它不会隐藏权限或验收边界。派发提示必须自包含：执行者只拿到这份合同和它列出的材料，不继承编排者的历史。

```text
包 ID：
能力级别：FLAGSHIP_DIRECT | BOUNDED_EXECUTION | MECHANICAL
运行模式：STANDARD | FALLBACK

当前 base SHA：（git fetch <远端> 后取远端主分支或列明分支的 SHA；不取未核对的本地分支）
worktree：（仓库目录之外）
branch：

目标与可观察结果：（做完后别人能看到/跑出什么）
行为合同：（输入→输出、兼容性、失败时怎样）
必读材料：（路径清单；不列的不读）

白名单：（glob，一行一条；审核用 check-package-whitelist 机检）
黑名单：（项目 redline 自动生效，这里写本包额外禁区）
必须保持：（旧数据/旧接口/旧行为）
明确非目标：

允许的状态变更：
- 新增依赖：是/否
- 修改状态文档（路线图/排期/决策）：是/否
- merge：是/否
- push：是/否
- deploy/生产操作：是/否
- 资源清理：是/否

验收命令与预期观察：
必须回传的证据：（原始输出、截图、日志路径；基线红要给原始数字）
预算：（模型调用/付费生成/时间上限）
停止与升级条件：（遇到什么立刻停、回报谁）

交付要求：
- 单一交付 commit：
- 报告路径：（热区目录内）
- 报告必含：真实 commit/diff、逐项验证结果、做了/没做/为什么、合同偏离、剩余风险
- 回调对象：
```
