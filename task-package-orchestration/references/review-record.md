# 审核记录

审核只基于实际产物和证据；执行者的总结只能当索引，不能替代复核。

```text
任务包：
审核结论：ACCEPT | REWORK_ONCE | ESCALATE

实际 base / worktree / commit：（与合同 base 是否一致）
白名单与黑名单检查：（粘贴 check-package-whitelist 原始输出）
语义 diff 结论：（改了什么行为；有无合同外语义变化）
验收复跑及原始结果：（审核者自己跑，不抄报告）
运行日志 / 截图 / 真机证据：
基线对照：（适用门“无新增红”；给原始数字）
合同偏离：
剩余风险与未验证项：

下一步已授权动作：（ACCEPT 本身不授权 merge/push/deploy）
若为 REWORK_ONCE，唯一返修缺口：（精确、机械、合同不变）
若为 ESCALATE，触发原因与所需决策：
```

## 三态判据

- **ACCEPT**：合同内结果和证据全部满足。
- **REWORK_ONCE**：合同不变、缺口明确且可一次机械修正。只给一次；返修仍不满足 → ESCALATE。
- **ESCALATE**：一次返修仍失败、根因不明、发现隐藏依赖、范围或合同需要变化、触发风险/权限停止条件。新目标、新范围、新验收口径必须开新包，不能伪装成第二轮返修。
