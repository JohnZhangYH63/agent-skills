# 跨项目切包约束

在两个以上项目里成立的约束写这里；只和一个项目有关的写该项目 `AGENTS.md` 的「切包约束」节。每条必带日期、原因与**退场条件**；退场条件成立就删（`doctor.mjs` 超 90 天会自动提示复核）。拆包时把与本包有关的条目原样贴进合同的「适用的切包约束」。

| 日期 | 约束 | 原因 | 退场条件 |
|---|---|---|---|
| 2026-11-10 | base 取 `git fetch` 之后的远端 `<remote>/<main_branch>` SHA，不取未核对的本地主分支或原生默认 `origin/HEAD` | 主检出落后、分叉，或原生 `--worktree` 默认取 `origin/HEAD` 时，会在错分支/过期代码上实现 | 各宿主原生 worktree 均能直接按 `AGENTS.md` 指定远端主分支对齐时删 |
| 2026-11-10 | 已在宿主独立 worktree 内直接复用（禁套娃）；手工建 worktree 放仓库目录外（主检出跑 dev 监听时避开仓内的 `.claude/worktrees/`） | 套娃会导致宿主 UI 面板失联；仓库内 worktree 会被 Next/Tailwind 等文件监听扫进主检出 | Claude Code 原生 worktree 改为默认存仓库目录外且全宿主默认隔离时删 |
| 2026-11-10 | 项目红线只写在 `AGENTS.md` frontmatter，脚本不带自己的红线数组 | 曾出现正文、配置文件、脚本硬编码三份红线并存，改一处漏两处 | 三端宿主均原生读取同一份只读路径配置物理禁写时删脚本留配置 |
| 2026-11-10 | 并行的包先跑 `check-disjoint`，共享接口先冻结成合同 | 两个执行者改同一文件，后合并的一方覆盖前一方且无人察觉 | 宿主多代理调度器原生内置文件锁/不相交静态检查时删 |
| 2026-11-11 | 文件域不相交不等于运行态隔离：并行执行或跑验收前，端口、Compose 项目、测试库须各自独占；新 worktree 先就绪依赖再跑 `gate-run` | 两个只读审核会话曾共用同一测试库并发重建导致假红；空 worktree 缺依赖直接报命令不存在 | 各仓测试与运行栈全部改为按进程随机端口/临时容器零共享时删 |
| 2026-11-11 | 审核者的绿灯只对它工具面能看见的部分成立：涉及 UI/运行态却只有构建/CLI 的审核不得签完整 `ACCEPT`；`wide`/`closed` 泳道优先异构模型交叉审 | 曾有 6 包并行 build/tsc/test 全绿，浏览器点三下现三处不可用；同模型自审会漏同源事实错 | 永久保留（工具面可观察性边界与模型能力强弱无关） |
| 2026-11-12 | 【仅后端查询包适用】① 跨模块只读函数（`get_*/list_*/current_*`）禁隐式写库与行锁，列表消费配批量入口；② 读路径到期结算先无锁判条件再窄化加锁；③ 聚合下推 SQL，禁超大 `limit` 拉回内存算（整班/十万行级压测只在阶段收口门跑，不进日常单包） | 单测小样本曾漏过循环跨模块单查（8,921 SQL）、读请求锁全班阻塞并发写（1.5s）与 `INT32_MAX` 内存聚合（15.8s） | 测试框架全局挂载 `GET` 零写零锁与 SQL 规模不变性钩子后删 |
